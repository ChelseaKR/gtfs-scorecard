Every route, one map.

The route shapes of every tracked feed record, drawn from each feed's own GTFS and combined on a single map. 8436 routes from 345 feed records are on it. Recolour by route type or by the scorecard's data-quality grade, and select a line for the named operator and a link to its scorecard.

This map is a visual extra, not the accessible way to read the data. A map of this many route lines can't be a data table. For a screen-reader and keyboard friendly view, use the alphabetical scorecard list; each scorecard carries a route-by-route table of its lines.

  • Coverage changes since each feed's prior check.
  • Each scorecard (for example Unitrans) lists its routes and stops in a table.

Routes are one representative shape per route, simplified for the combined view; zoom in for detail. Tiles are served as a single PMTiles archive over HTTP range requests. Basemap: OpenFreeMap, © OpenStreetMap contributors. Data: this scorecard, CC BY 4.0.
