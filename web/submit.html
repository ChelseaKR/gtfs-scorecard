Give us the link to your published GTFS feed and we will start scoring it. You do not need an account or to know what YAML is. Submitting opens a pull request for a person to review before anything goes live.

Just want a one-off grade without being added to the list? Request a score through the GitHub-backed path or run the scorer locally.

A direct link to your GTFS .zip. If you are not sure, your scheduling vendor or your page on the Mobility Database has it.

Primary location (required) Use the two-letter ISO country code. This identifies the feed's primary catalog location; it does not limit a service that crosses a border. Subdivision is optional for national, cross-border, city-state, or genuinely unlocated feeds. If you provide it, include both the ISO 3166-2 code and the local practitioner-facing name.
GTFS-Realtime URLs (optional) Leave these blank if you do not publish realtime. That is not counted against your grade.
